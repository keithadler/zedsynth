ZedSynth.

A versatile software synthesizer.

Four oscillators with eleven modes, two filters with ten, three LFOs, five envelopes, a modulation mixer and effects. Nearly four hundred factory patches. Free software since 2005, written by Sean Bolton as WhySynth, carried forward under a new name with his blessing.

The oscillators

Four of them, each able to be any of eleven things:

  • minBLEP, for the analogue shapes without the aliasing
  • Wavecycle and chorused wavecycle
  • Asynchronous granular
  • Three kinds of FM
  • Waveshaper
  • Noise
  • PADsynth, Paul Nasca's algorithm, for wide evolving pads
  • Phase distortion, which is the Casio CZ's way of making a sound: bend where a cosine is inside its own cycle and the harmonics arrive without a filter being involved. The three CZ resonant shapes are here by name, along with the paired waveforms and the octave modulation.

On the name

This was WhySynth through version 2.1.4. Sean Bolton, who wrote it, is taking his own WhySynth work toward Cortex-M7 hardware and asked that this line of development take a name of its own. It continues the joke the family was already telling: Xsynth, then Xsynth-DSSI, then WhySynth, now ZedSynth.

Your patches still load. The file format has not changed and still identifies itself as WhySynth's, so banks pass between the two in both directions. WHYSYNTH_DEFAULT_BANK still works. What did change is the plugin identifier, so a host will not find ZedSynth in a session saved with WhySynth: it looks the instrument up by that identifier. Load ZedSynth and load your patch into it.

What is new since 2.1.4

The same engine, built for 2026. It is a CLAP and an LV2 plugin on Linux, macOS and Windows, with an Audio Unit and a standalone on top of the CLAP, built with CMake, with tests and CI and a command line renderer. FFTW, DSSI, liblo, ALSA and GTK are no longer required to build it. The DSSI plugin and its GTK2 editor still build on Linux when their libraries are installed.
